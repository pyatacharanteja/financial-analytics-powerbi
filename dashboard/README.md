# Power BI Desktop Output

The source-controlled Power BI project lives in `powerbi-project/`.

## Open the project
1. Install a current version of Power BI Desktop.
2. Enable **Power BI Project (.pbip) save option** if required under Preview features.
3. Clone/download this repository.
4. Open `powerbi-project/SP500FinancialAnalytics.pbip`.
5. Refresh the semantic model and approve the public Web data-source connection when prompted.
6. Import `powerbi/theme.json` as the report theme.
7. Build/validate the three report pages described in the main README and `powerbi/REPORT_BUILD_SPEC.md`.
8. Save As → **Power BI Desktop file (.pbix)** and save the result here as `sp500_financial_analytics.pbix`.

## Important
A `.pbix` file is generated by Power BI Desktop. The repository keeps the text-based PBIP/TMDL source so model logic, queries, and changes remain reviewable in Git.
